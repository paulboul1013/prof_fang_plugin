# prof_fang_plugin

泡芙方的英聽訓練三件套，速聽，高斯模糊，環境噪音，方便加強你的英聽

## 功能特色

- `Speed` 模式：1x / 1.5x / 2x / 2.5x / 3x
- `Gaussian Blur`（高斯模糊）模式：強度 1–5（Light ~4000 Hz → Heavy ~900 Hz）
  - 用高斯曲線的濾波器移除高頻：子音細節（s、f、th）變模糊，母音和節奏保留，逼大腦用上下文與重音去補字
  - 頻率響應平滑、沒有共振或振鈴；切換與調整強度時會淡入淡出，不會爆音，並小幅補償音量
  - 舊版 `Low-Pass` 的 light / medium / heavy 設定會自動轉成強度 1 / 3 / 5
- `Noise` 模式：使用 `assets/noise/` 內的本地 mp3（目前為 `People Talking Ambience Sound Effect.mp3`）
- 同一時間僅允許一種模式啟用
- 切到 `OFF` 會還原正常播放

## 目前可用影音平台

- youtube
- twitch

## 支援瀏覽器平台

- Google Chrome
- Microsoft Edge

## 在 Chrome 和 Edge 載入

1. 開啟 `管理擴充功能`
2. 按下`載入解壓縮`
3. 選擇`此專案`的資料夾

## 備註
如果剛開啟插件時，功能沒有反應的話，F5按鍵重置一下
