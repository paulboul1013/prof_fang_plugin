# prof_fang_plugin

泡芙方的英聽訓練三件套，速聽，高斯模糊，環境噪音，方便加強你的英聽

## 功能特色

- `Speed` 模式：1x / 1.5x / 2x / 2.5x / 3x
- `Gaussian Blur`（高斯模糊）模式：強度 1–5（Light ~4000 Hz → Heavy ~900 Hz）
- `Noise` 模式：使用 `assets/noise/` 內的本地 mp3（目前為 `People Talking Ambience Sound Effect.mp3`）
- 同一時間僅允許一種模式啟用
- 切到 `OFF` 會還原正常播放

## 目前可用影音平台

- youtube
- twitch

## 支援瀏覽器平台

- Google Chrome
- Microsoft Edge

## 在 Chrome 和 Edge 載入

1. 開啟 `管理擴充功能`
2. 按下`載入解壓縮`
3. 選擇`此專案`的資料夾

## 備註
如果剛開啟插件時，功能沒有反應的話，F5按鍵重置一下
